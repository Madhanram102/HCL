# HCL Hackathon Practice

A collection of Java programs built while practicing for the **HCL Hackathon**. Each file is a self-contained problem focused on core Object-Oriented Programming (OOP) concepts such as classes, inheritance, polymorphism, abstraction, and encapsulation.

## Overview

This repository contains practice solutions to typical hackathon-style problems. Each program models a real-world scenario (banking, payroll, hospital billing, etc.) using clean OOP design.

## Programs

| # | File | Description |

| 2 | `EmployeePerformance.java` | Employee performance calculation classes |

## Concepts Covered

- **Classes & Objects**: modeling real-world entities
- **Inheritance**: base classes extended by specialized subclasses
- **Polymorphism**: method overriding for type-specific behavior
- **Abstraction**: abstract classes and interfaces
- **Encapsulation**: private fields with getters and setters

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- Any IDE (IntelliJ IDEA, Eclipse, VS Code) or a terminal

### Clone the repository

```bash
git clone https://github.com/Madhanram102/HCL.git
cd HCL
```

### Compile and run

```bash
javac VehicleRental.java
java VehicleRental
```

Replace `VehicleRental` with any file name from the table above.
